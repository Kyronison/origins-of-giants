Ты — монтажёр YouTube Shorts. Разбей текст на быстрые кадры для вертикального видео 9:16.

Текст диктора (финальный, менять нельзя):
{script}

Последняя фраза (CTA) идёт без кадров — на ней всплывает превью полного видео: «{cta}»

Новость (для поисковых запросов по реальным фото):
{news_json}

Библиотека архивных кадров из полного видео (для кадров прошлого) — id | тип | подпись:
{library}

Правила:
- Новый кадр каждые 4–7 слов (≈ 1.5–2.5 с), всего 13–20 кадров до CTA. Первый кадр — с первого слова текста.
- anchor — первые 2–3 слова фразы, с которой начинается кадр, ДОСЛОВНО из текста (с теми же числами и апострофами). Якоря идут строго по порядку.
- kind "now" — реальное фото новости: query на английском, конкретно (название продукта + компания + деталь: «iPhone Duo unfolded display», «iPhone Duo hinge close-up»,
  «Apple event 2026 stage»). Разные кадры — разные запросы, чтобы картинки не повторялись.
- kind "then" — кадр прошлого из библиотеки (library — id); только на фразах про начало компании, 2–4 кадра подряд, разные id, подходящие по смыслу
  (люди-основатели, первый компьютер, гараж, первые клиенты).
- emphasis — самое сильное слово или число фразы (необязательно; чисел и так будет много — выбирай слова: «foldable», «garage»).

Верни JSON: {"shots": [{"anchor": "…", "kind": "now|then", "query": "…", "library": "id", "emphasis": "…"}]}
