Разложи короткую документальную историю на 4–6 визуальных сцен по 4–9 секунд.
Текст диктора, не менять:
{script}
Концовка на спокойной карточке полного выпуска: «{cta}»
Проверенный эпизод:
{news_json}
Доступные архивные материалы: id | тип | точная подпись
{library}

Первая сцена — первое слово. anchor — первые 2–3 слова фразы дословно из текста.
Новая сцена при смене предмета рассказа. Не менять фотографии ради таймера.
На словах о человеке, документе или месте используй именно его. Не подставляй случайный
портрет, похожую компанию или снимок другой даты. Нет подходящего материала — конкретный query.
kind=then — исторический материал с library id;
kind=now — общая брендовая иллюстрация только там, где она не выдаётся за историческое доказательство.
Не повторять изображение. emphasis — ключевое слово, не число.
Для одного-двух действительно описанных механизмов добавь panel: flow — последовательность
из 2–3 шагов, названных диктором. Без географических карт, неподтверждённых стрелок и новых цифр.
headline — короткая дословная фраза диктора, nodes — дословные непрерывные фразы из текста
по 2–5 слов, до 36 знаков. Они должны описывать последовательность, а не случайные цитаты.
Заголовок не повторяет надписи узлов. Схема явно подписана как иллюстрация.
Остальные сцены — photo, с точным архивным материалом. Не выдавать flow за фото героя.
